# Nexar-AI — App

This is the Next.js 15 application for Nexar-AI. The root `README.md` contains the full documentation, architecture overview, and contribution guide.

For quick reference:

- **Getting started:** see [../README.md#-getting-started](../README.md#-getting-started)
- **Environment variables:** copy `.env.example` to `.env.local` and fill in the required values
- **Run dev server:** `npm run dev` (from this directory)
- **Run tests:** `npm test`
- **Build:** `npm run build`

Refer to the root [`README.md`](../README.md) and [`CONTRIBUTING.md`](../CONTRIBUTING.md) for everything else.
